# Epic and task migration skill

## Project brief

What: A skill that migrates epics and tasks from the old ticket scheme to the new one
How: To be designed after housekeeping-rules-estimates closes
Why: Existing epics must carry the new fields so calibration and retros read one scheme

## Description

Requested 2026-10-25 while epic housekeeping-rules-estimates was running: "Skill to add: migrate epics/tasks from old scheme to new one. Can be started after current work gets delivered." To be planned (discovery, design, gate) only after housekeeping-rules-estimates is closed, since the new scheme (points, expected_minutes, expected_tokens, actual fields, RETRO.md) is what that epic defines.

## Goals

- G1: A workbench skill migrates existing epics and their task files from the old ticket scheme to the new one defined by epic housekeeping-rules-estimates; the exact field mapping and which phases (todo, in-progress, done) are in scope are settled at that epic's gate.

## Non-goals

- Starting before housekeeping-rules-estimates is closed.
