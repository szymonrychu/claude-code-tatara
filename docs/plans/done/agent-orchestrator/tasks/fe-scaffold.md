# fe scaffold

## Requirement

Create `frontend/` (D12).

`package.json`:
- Every dependency of the UI: react and react-dom 19.3.x, @mui/material 9.5.x, @emotion/react, @emotion/styled, react-virtuoso 4.18.x.
- Every dev dependency: vite 8.3.x, @vitejs/plugin-react, typescript, vitest 5.0.x, jsdom, @testing-library/react, @testing-library/user-event, eslint 10.13.x, typescript-eslint, eslint-plugin-react-hooks, openapi-typescript 7.13.x.
- No later task adds a dependency.
- Scripts: `dev` (vite), `build` (`tsc -b && vite build`), `test` (`vitest run`), `lint` (`eslint src --max-warnings 0`).
- `package-lock.json` is generated by `npm install` and committed.

Configuration:
- `vite.config.ts`: outDir `dist`; dev proxy `/api` to http://localhost:8000; vitest environment node, with DOM tests opting in through `// @vitest-environment jsdom`.
- `tsconfig.json`: strict.
- `eslint.config.js`: flat config with typescript-eslint and react-hooks.

Sources:
- `index.html` loads `src/main.tsx`, which renders `<App />` into #root.
- `App.tsx` renders the application name.
- `App.test.tsx` renders App in jsdom and finds the name.
